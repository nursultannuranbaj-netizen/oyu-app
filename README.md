# Oyu — казахский орнамент

Мобильное приложение для Android: учит смыслам казахских орнаментов в формате коротких уроков, как в Duolingo. Три языка (қазақша / русский / English), сердца и опыт, серия дней, чекпоинты, коллекция изученных орнаментов, вход по коду из письма и синхронизация прогресса.

Пять модулей, все 42 орнамента из книги: «Рога и скот» (11), «Птицы и малые существа» (8), «Растительный мир» (7), «Небо и вода» (7), «Юрта и быт» (9). Тексты взяты из методического документа курса; в карточки вошли только смыслы, описанные в источнике.

Стек: Expo (React Native + TypeScript), Supabase для входа и хранения прогресса.

## Запуск на телефоне

Нужно: компьютер с [Node.js](https://nodejs.org) 20 или новее и Android-телефон в той же Wi-Fi сети.

```bash
npm run setup      # ставит зависимости в версиях под текущий Expo SDK
npx expo start     # покажет QR-код
```

На телефоне установите **Expo Go** из Google Play и отсканируйте QR-код. Приложение откроется сразу, без сборки.

Если телефон пишет «Failed to download remote update» или не может подключиться (например, в общей или университетской Wi-Fi сети), запустите через туннель:

```bash
npm run tunnel     # то же, что npx expo start --tunnel ngrok
```

Без настроек Supabase приложение работает полностью, только прогресс хранится на одном телефоне, а раздел «Аккаунт» в настройках показывает, что синхронизация не настроена.

## Вход и синхронизация (Supabase)

1. Создайте бесплатный проект на [supabase.com](https://supabase.com).
2. **SQL Editor → New query**: вставьте содержимое `supabase/migrations/0001_progress.sql` и нажмите **Run**. Появится таблица `progress`, где каждый пользователь видит только свою строку.
3. **Authentication → Sign In / Providers → Email**: вход по email должен быть включён.
4. **Authentication → Emails → Templates → Magic Link**: замените текст письма так, чтобы в нём был код, например:
   ```html
   <h2>Код для входа в Oyu</h2>
   <p>Ваш код: <strong>{{ .Token }}</strong></p>
   ```
   Приложение спрашивает код из письма, а не ссылку.
5. **Project Settings → API**: скопируйте `Project URL` и `anon public` ключ. Скопируйте `.env.example` в `.env` и вставьте их туда.
6. Перезапустите `npx expo start`.

Встроенная почта Supabase отправляет лишь несколько писем в час. Для реальных пользователей подключите свой SMTP (Authentication → Emails → SMTP Settings).

Как работает синхронизация: телефон хранит прогресс локально и работает без интернета. После входа и после каждого урока локальная копия объединяется с облачной: пройденные уроки складываются, опыт берётся больший, серия дней — из более свежей копии. Сердца и язык остаются свои на каждом устройстве.

## Сборка APK и публикация

```bash
npm install -g eas-cli
eas login                      # аккаунт expo.dev, бесплатно
npm run build:apk              # APK для установки на телефон, ссылка придёт в консоль
eas build -p android --profile production   # .aab для Google Play
```

Перед сборкой положите ключи Supabase в EAS: `eas env:create --name EXPO_PUBLIC_SUPABASE_URL --value ...` (и так же для `EXPO_PUBLIC_SUPABASE_ANON_KEY`), либо в `eas.json` в раздел `env` профиля.

Для Google Play нужен аккаунт разработчика (разовый взнос $25). Идентификатор приложения задан в `app.json` → `android.package` (`kz.oyu.app`); поменяйте его на свой до первой публикации, потом его изменить нельзя.

## Структура

```
App.tsx                    состояние приложения, навигация, шапка и вкладки
src/content.ts             учебный контент модулей 1–2 на трёх языках
src/content_more.ts        модули 3–5
src/art.ts                 временные векторные иллюстрации орнаментов
src/lesson.ts              логика урока: шаги, проверка ответов, повтор ошибок, итог
src/progress.ts            прогресс: сердца, серия дней, опыт, слияние при синхронизации
src/sync.ts                Supabase: вход по коду, синхронизация
src/storage.ts             хранение прогресса на телефоне
src/i18n.ts                надписи интерфейса на трёх языках
src/theme.ts               цвета (светлая и тёмная тема) и шрифты
src/screens/               экраны: путь, урок, итог, коллекция, настройки
supabase/migrations/       схема базы данных
scripts/selftest.ts        проверки контента и логики: npm run selftest
```

## Как добавить модуль

1. В `src/content.ts` добавьте орнаменты в `orn` (тексты в порядке [KAZ, RUS, ENG], три задания, индекс правильного ответа `a`) и модуль в `modules` с юнитами и пятью вопросами чекпоинта.
2. В `src/art.ts` добавьте иллюстрацию под ключом из поля `art` и палитру в `PAL`.
3. Запустите `npm run selftest`: он проверит, что у каждого орнамента есть картинка, все ответы указывают на существующие варианты, а чекпоинты ссылаются на реальные орнаменты.

## Иллюстрации

Сейчас орнаменты нарисованы простыми векторными формами в `src/art.ts`. Финальные иллюстрации делаются по промтам из документа курса и перерисовываются в SVG. Чтобы заменить картинку, верните её SVG-разметку из функции нужного орнамента в `ART` (поле зрения 120×120) или переключите компонент `Ornament` в `src/components/ui.tsx` на файлы изображений.
